# นำเสนอผลงานก่อสร้าง (site-present) เวอร์ชัน 2.0

สร้างสไลด์รายงานความก้าวหน้าต่อคณะกรรมการจากข้อมูลใน site-control โดยอัตโนมัติ นำเสนอเต็มจอ หรือบันทึกเป็น PDF

**ลิงก์แอป (หลังติดตั้ง):** https://patarakorn-bas.github.io/site-present/

## ติดตั้งบน GitHub Pages (~10 นาที)

1. github.com → **New repository** → ชื่อ **`site-present`** (ตัวเล็กทั้งหมด) → **Public** → Create
2. **uploading an existing file** → แตกไฟล์ zip แล้วลาก **ทุกไฟล์และโฟลเดอร์ในโฟลเดอร์ `site-present`** ลงไป (ต้องเห็น `index.html` อยู่ชั้นบนสุด และมีโฟลเดอร์ `icons` `vendor`) → **Commit changes**
3. **Settings → Pages** → Deploy from a branch → **main / (root)** → Save
4. รอ 1–2 นาที แล้วเปิดลิงก์ด้านบน → ติดตั้งเป็นแอป (คอมพิวเตอร์: ไอคอนท้ายช่องที่อยู่เว็บ • iPad: แชร์ → เพิ่มไปยังหน้าจอโฮม)

> ต้องอยู่ในบัญชี GitHub เดียวกับ site-control จึงอ่านข้อมูลจาก site-control ได้โดยตรง

## ใช้งาน

1. เลือกโครงการ (จาก site-control หรือนำเข้าไฟล์ Excel ที่ส่งออกจาก site-control / site-plan)
2. กรอกข้อมูลการประชุม ปัญหาอุปสรรค เรื่องเสนอพิจารณา เพิ่มรูปถ่ายหน้างาน
3. เลือก **แบบสั้น** (5 หน้า สำหรับผู้บริหาร) หรือ **แบบเต็ม** (คณะกรรมการ) และเปิด-ปิดสไลด์แต่ละหน้าได้
4. กด **นำเสนอ** (เลื่อนด้วยลูกศร คลิก หรือปัดหน้าจอ • Esc ออก) หรือ **พิมพ์ / PDF** → เลือก "บันทึกเป็น PDF"

ทุกครั้งที่นำเสนอ ระบบเก็บผลงาน ณ วันที่รายงานไว้ แล้วแสดงเป็นจุดบน S-Curve ในครั้งถัดไป

## เครื่องมือระดับ Pro (เวอร์ชัน 2.0)

- **PowerPoint (.pptx)** แก้ไขได้ทุกชิ้น กราฟเป็นกราฟของ PowerPoint จริง และมีบทพูดใน Notes ทุกหน้า
- **นำเสนอ 2 จอ** จอผู้นำเสนอ (สไลด์ปัจจุบัน สไลด์ถัดไป บทพูด จับเวลา) + จอผู้ชม: ลากหน้าต่างจอผู้ชมไปจอโปรเจกเตอร์ แล้วกดปุ่มเต็มจอ (ต้องอนุญาต pop-up ครั้งแรก)
- **ระหว่างนำเสนอ** P ปากกา • L เลเซอร์ • E ลบหมึก • B จอดำ • N บทพูด (โหมดจอเดียว) • Esc ออก
- **สรุปสำหรับผู้บริหาร** เขียนให้อัตโนมัติ รวมความก้าวหน้าเทียบกับรายงานครั้งก่อน
- **บทพูด** สร้างอัตโนมัติทุกหน้า แก้เองได้ที่รายการสไลด์ด้านข้าง
- **สไลด์เพิ่มเติม** ใส่หัวข้อ เนื้อหา และรูปประกอบได้เอง
- **สำรอง/กู้คืนข้อมูล** ที่หน้าหลัก

> ไฟล์ PowerPoint ใช้ฟอนต์ TH SarabunPSK เครื่องที่เปิดไฟล์ต้องติดตั้งฟอนต์นี้ (เครื่องราชการส่วนใหญ่มีอยู่แล้ว)

## ข้อมูลอยู่ที่ไหน

- อ่านข้อมูลจาก site-control แบบอ่านอย่างเดียว ไม่แก้ไขข้อมูลใน site-control
- ปัญหาอุปสรรค เรื่องเสนอ รูปถ่าย เก็บในเครื่องนี้ (แยกจาก site-control)
- **iPad:** แอปที่ติดตั้งบนหน้าจอโฮมแต่ละแอปเก็บข้อมูลแยกกัน → ใช้ **นำเข้าจากไฟล์ Excel** ที่ส่งออกจาก site-control

## อัปเดตเวอร์ชันใหม่

อัปโหลดไฟล์ใหม่ทับใน repository เดิม → เปิดแอป กด **อัปเดต** เมื่อมีข้อความ • เวลาขอแก้ไข แนบ zip เวอร์ชันล่าสุดมาด้วย
